# Array Map in 100 Seconds

Array map creates a new array by calling a function on every element of another array [V1 00:00].

Unlike a for loop that mutates state, map is declarative and describes how to build the new array [V1 00:34].

The function passed to map receives the current element and its index, and returns the new value [V1 00:53].

Using map when you do not need the resulting array is an anti-pattern; a plain loop is the better tool [V1 01:24].
